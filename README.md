# 部首あわせ (bushu-awase)

部品(「木」「目」「亻」…)を組み合わせて漢字を作るパズル。**木 ＋ 目 ＝ 相**。

- 盤に並んだ8枚の部品から2つ以上えらんで「あわせる」。配置(左右・上下・囲み)は問わず、部品の組で判定します。
- 部品はさらに分けても通ります(日 ＋ 土 ＋ 寸 ＝ 時、木 ×3 ＝ 森)。同じ部品は盤にある枚数までしか使えません。
- 盤は漢字の構造データ(IDS)から自動生成します。同じ種(`?seed=`)なら同じ盤、種なしならその日の盤です。
- 「この盤で作れる字の数」は同梱データの範囲で数えた数です。データにない組み合わせは「データにない」と言い、「実在しない」とは言いません。

公開: https://bushu-awase.vercel.app

## IDS データとライセンス

- CHISE の IDS と、それを元にした cjkvi-ids の `ids.txt` は **GPLv2**(cjkvi-ids の README で確認)。このアプリは同梱すると全体を GPL にする必要があるため、**同梱していません**。
- 代わりに、遊べる範囲(526字)の分解を**自作**しました: `src/data/kanji.js`(1行 =「字 IDS よみ」)。ライセンスは MIT。
- 自作データの誤りを拾うため、開発時に手元で cjkvi-ids と突き合わせました(照合用のファイルはリポジトリに入れていません)。一致しなかったのは10字で、どれも分け方の流儀の違いです。このアプリでは学習用に分かりやすい分け方を優先しています(例: 品 = 口×3、果 = 田＋木、東 = 木と日の重ね)。字源の解説ではありません。
- 偏の変形(亻 氵 扌 忄 礻 艹 辶 …)は独立した部品として扱います。囗(くにがまえ)と口は別の部品です。

## 開発

```sh
pnpm install
pnpm dev     # http://localhost:5950
pnpm test    # Vitest
pnpm build
```

- `src/lib/ids.js` — IDS の構文解析と、部品への切り分け方の列挙
- `src/lib/dict.js` — データから辞書(切り分け方 → 字 の索引)を作る
- `src/lib/judge.js` — 作れるか/作れないかの判定(純粋関数)
- `src/lib/puzzle.js` — 種つき乱数で盤を生成(作れる字が 8〜24 字になる盤を探す)
- `src/app.js` — 描画と配線。`window.__app` で状態・`submit(parts)`・`newBoard(seed)`・`answers()`・`solveAll()` を公開
